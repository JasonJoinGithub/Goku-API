# 主题：GOKU 悟空 · Token 与 AI 网关业务

> **一句话**：卖 token 是「包壳生意」，**上游决定命运**；合规分销 + 本地化集成是首推路径，GOKU 是已经跑起来的原型。

## 已经想清楚的

- **五种上游 = 五种命运**：成本递减，风险递增。
- 暴利与合法很难兼得；官转的净利率可能为负。
- 真正的收入构成常是多数人没想到的那三块（详见原文）。
- 四条路：**A 国产模型合规分销（首推）** / B 境外主体做海外用户 / C 卖铲子不挖金 / D 号池·拼车·逆向（红线，别碰）。
- 2026 年的现实对「自己包壳卖」不利，争点在合规与供给，不在技术。
